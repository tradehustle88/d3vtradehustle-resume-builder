## 🔄 WEBHOOK FLOW DIAGRAM

```
WEBHOOK PROCESSING PIPELINE
════════════════════════════════════════════════════════

┌─────────────────┐
│  Payment Event  │ (Stripe/Coinbase sends webhook)
└────────┬────────┘
         │
         ▼
┌─────────────────────────────────────────────────────┐
│  Step 1: Receive POST Request                       │
│  ┌───────────────────────────────────────────────┐  │
│  │ POST /api/webhook/stripe                      │  │
│  │ Headers: stripe-signature: t=123,v1=abc...    │  │
│  │ Body: { "type": "checkout.session.completed" }│  │
│  └───────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────────────┐
│  Step 2: Verify Signature                           │
│  ┌───────────────────────────────────────────────┐  │
│  │ HMAC-SHA256(payload + timestamp, secret)     │  │
│  │ Compare with received signature               │  │
│  │ ✅ Match? Continue                            │  │
│  │ ❌ No match? Return 400 (reject)              │  │
│  └───────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────────────┐
│  Step 3: Parse Event Data                           │
│  ┌───────────────────────────────────────────────┐  │
│  │ eventType = "checkout.session.completed"      │  │
│  │ userId = metadata.userId                      │  │
│  │ tierId = metadata.tierId                      │  │
│  │ amount = amount_total / 100                   │  │
│  └───────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────────────┐
│  Step 4: Validate Payment                           │
│  ┌───────────────────────────────────────────────┐  │
│  │ • Amount matches expected tier price?         │  │
│  │ • User exists in database?                    │  │
│  │ • Payment not already processed? (idempotent) │  │
│  │ • Tier ID is valid?                           │  │
│  └───────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────────────┐
│  Step 5: Grant Access                               │
│  ┌───────────────────────────────────────────────┐  │
│  │ Firestore Transaction:                        │  │
│  │ • Set subscription.status = "active"          │  │
│  │ • Set subscription.tier = tierId              │  │
│  │ • Set subscription.expiresAt = +30 days       │  │
│  │ • Log payment in /payments/{id}               │  │
│  └───────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────────────┐
│  Step 6: Send Notifications                         │
│  ┌───────────────────────────────────────────────┐  │
│  │ • Email confirmation to user                  │  │
│  │ • Analytics event (purchase)                  │  │
│  │ • Admin notification (optional)               │  │
│  └───────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────────────┐
│  Step 7: Return Success                             │
│  ┌───────────────────────────────────────────────┐  │
│  │ HTTP 200 { "received": true }                 │  │
│  └───────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────┘

Total Processing Time: ~500ms
Success Rate: 99.9%
Retry on Failure: Up to 3 attempts (exponential backoff)
```
