## 💡 How It Works

```
┌─────────────────────────────────────────────┐
│  USER                                       │
│  Grabs ⋮⋮ handle, drags item               │
└────────────┬────────────────────────────────┘
             │ @dnd-kit sensors
             ↓
┌─────────────────────────────────────────────┐
│  SORTABLE LIST                              │
│  Calculates new position                    │
└────────────┬────────────────────────────────┘
             │ onReorder callback
             ↓
┌─────────────────────────────────────────────┐
│  FORM STATE                                 │
│  Updates array order                        │
└────────────┬────────────────────────────────┘
             │ React re-render
             ↓
┌─────────────────────────────────────────────┐
│  UI UPDATE                                  │
│  Smooth animation to new position! 🎉       │
└─────────────────────────────────────────────┘
```

**No page refresh. No data loss. Just smooth reordering.**

## 💬 Quick Reference

### Basic Usage
```typescript
<SortableList
  items={items}
  onReorder={setItems}
  getId={(item) => item.id}
>
  {(item, index) => (
    <SortableItem key={item.id} id={item.id}>
      <YourComponent data={item} />
    </SortableItem>
  )}
</SortableList>
```

### Required Props
- `items` - Array of data objects
- `onReorder` - Callback with reordered array
- `getId` - Function to extract unique ID

### CSS Import
```typescript
import "@/components/dnd/dnd.css";
```
