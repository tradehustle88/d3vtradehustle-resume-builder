# Trade Hustle Resume Builder

[![Firebase Deploy](https://github.com/tradehustle88/d3vtradehustle-resume-builder/actions/workflows/deploy.yml/badge.svg?branch=main)](https://github.com/tradehustle88/d3vtradehustle-resume-builder/actions/workflows/deploy.yml)

Built for tradespeople. Backed by hustle.  
This is a Next.js + Firebase powered resume builder with AI integrations (Vertex AI, ActiveCampaign) designed to help trade professionals build, edit, and score resumes fast.
